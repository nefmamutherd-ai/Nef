### Desarrollo con Claude Code
- **Skill `ui-ux-pro-max`** (del kit de Tino): `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill`
  y `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill` (necesita Python 3). Para revisar pantallas
  **sin salirse de `docs/DISENO.md`**.
- **MCP** (como en Tino): Supabase MCP solo al proyecto de desarrollo y en solo lectura; Context7;
  Playwright MCP; 21st.dev Magic solo como inspiración para la landing.
- **Estructura de trabajo** (Tino y Velora): `docs/PROGRESO.md`, `docs/DECISIONES.md`, `docs/BUGS.md`,
  comandos `/siguiente-fase`, `/revisar-seguridad`, `/cerrar-sesion`.
- **Lecciones de Prodigia** (reglas en `CLAUDE.md`): RLS y permisos con cada columna nueva; nada de
  "debería funcionar" sin prueba en navegador; cuenta de prueba fija; nunca pegar llaves en el chat;
  avisar si un pedido quedó sin hacer.
- **Del validador de pagos**: PIN por turno en caja, montos enteros en pesos, anon key + funciones con
  PIN/token en vez de `service_role`, lectura de alertas de Bancolombia con Apps Script.
- **Capacitor** (plan Android de Prodigia): solo si la caja necesita ser app instalada.
