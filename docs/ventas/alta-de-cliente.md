# Alta de un cliente nuevo — lista de chequeo

## Pídele al cliente (por WhatsApp, el día que acepta)
- [ ] Logo (imagen) y color de la marca
- [ ] Nombre exacto como quiere que aparezca
- [ ] Link para pedir reseñas de Google (Perfil de Empresa → "Pedir reseñas")
- [ ] WhatsApp, Instagram, red y clave del WiFi
- [ ] Café/restaurante: carta (foto o PDF) con precios
- [ ] Gimnasio: lista de máquinas para stickers y horario de clases
- [ ] Club: qué premios quiere dar y cuánto quiere devolver (3 %, 5 % u 8 %)
- [ ] Nombre y celular de quien va a manejar la caja/recepción

## En el panel (10 minutos)
- [ ] Crear el negocio con todos los datos
- [ ] Asignar los tags ya grabados (Tags → seleccionar → Asignar)
- [ ] Probar cada destino desde tu celular (NFC y QR)
- [ ] Club: crear premios, fijar el PIN de caja
- [ ] Copiar el link de estadísticas del dueño

## En el lugar
- [ ] Limpiar la superficie con alcohol antes de pegar
- [ ] Pegar stickers/placas y **probar cada uno** con Android y iPhone
- [ ] Enseñarle al cajero/recepción a sumar y canjear (2 minutos)
- [ ] Enviarle al dueño su link de estadísticas
- [ ] Foto del montaje (para tu portafolio, con permiso)

## Después
- [ ] Registrar el pago de la instalación en el panel
- [ ] Agendar el mensaje de mitad de piloto o de primera semana
